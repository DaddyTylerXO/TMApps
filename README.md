# TMApps

A collection of desktop apps for mail, security, creativity and AI-assisted work, managed through TMApps Launcher.

**[Download TMApps Launcher and apps](DOWNLOADS.md)** · [All release files](https://github.com/DaddyTylerXO/TMApps/releases/tag/tma-apps) · [Help and reports](SUPPORT.md) · [Security policy](SECURITY.md)

## Get started

Install [TMApps Launcher for Windows](https://github.com/DaddyTylerXO/TMApps/releases/download/tma-apps/TMApps-Launcher-Setup.exe), or choose a macOS/Linux installer from the [download index](DOWNLOADS.md). The launcher downloads app packages and checks their SHA-256 hashes. Choose a build matching your operating system and processor.

These are developing applications. Windows and Linux builds are unsigned; macOS builds are ad-hoc signed and are not notarized. Platform support varies by app. Read the app's own setup and security notes before use.

## Help and maintenance

Use each app's Help/KB and branch README for setup instructions. [SUPPORT.md](SUPPORT.md) links to public bug, feature and general issue reports. Send vulnerabilities through [private security reporting](https://github.com/DaddyTylerXO/TMApps/security/advisories/new).

[APP-STANDARDS.md](APP-STANDARDS.md) defines the compulsory app requirements. [MAINTENANCE.md](MAINTENANCE.md) records the cross-branch audit, known distribution/documentation gaps and the maintenance procedure. Installers and portable archives are distributed through GitHub Releases; the public GitHub Packages page currently has no published registry packages.
