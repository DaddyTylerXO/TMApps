# TMApps Launcher project instructions

For every launcher update, follow the standing KB maintenance requirements in
[.cursor/rules/kb-maintenance.mdc](.cursor/rules/kb-maintenance.mdc).

For all work, follow the sensitive-data publishing restrictions in
[.cursor/rules/security-data.mdc](.cursor/rules/security-data.mdc).

## Compulsory app standards

Follow [APP-STANDARDS.md](APP-STANDARDS.md) and [.cursor/rules/app-standards.mdc](.cursor/rules/app-standards.mdc) for every update. These requirements apply to all current and future TMApps apps; carry the standards and existing security and KB guidance into each new project.
