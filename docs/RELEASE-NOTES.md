# TMA-Libraries version notes

## 0.2.0-dev.1 — 22 October 2026

Electron desktop rebuild with a brown Finance-inspired shell, tabs and ten document choices. Adds transactional SQLite storage, legacy migration, assets/revisions, native copies, Trash/Restore and confirmed permanent deletion, rich-document templates, Books, spreadsheets, slides and PDF tools. Settings include search, support drafts, offline help, accessibility choices, autosave and templates.

Storage, representative format adapters and desktop workflows are checked; PDF redaction is independently checked. This is a development preview: full Office fidelity, complete editor tooling, memory targets, accessibility/standards, Word KB publication, Launcher and cross-platform distribution remain open. See VERIFICATION-0.2.0.md. Legacy source is retained for migration/reference.

## 0.1.0 — 21 October 2026

Initial Windows desktop foundation using Windows Forms and .NET Framework 4.8, with no required paid services or external packages.

- Offline plain-text notes, checklists, optional completion progress and side notes.
- Folders, favourites, recent documents, search and coloured tags.
- Atomic local saves, previous-save recovery and native workspace import/export.
- Autosave defaults to five seconds when changed; configurable from two to 300 seconds or disabled.
- First-run setup offers optional larger text/high contrast, both off by default. Feature tour can be replayed from the toolbar.
- Light, Grey and Black appearance; fixed keyboard shortcuts and Settings release notes.
- Leather Brown identity and white-folder executable/window icon.
- Word KB draft with setup, offline operation, recovery, error catalogue and performance guidance. Rendering, master KB linking and publication are pending.

Advanced editors and the other pending specification items are not included. No Launcher package, remote publication, encryption, sync, tray, connection indicator or support forms are claimed.
