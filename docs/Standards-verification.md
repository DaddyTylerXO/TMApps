# 0.2.0 standards verification

The update retains the red camera identity, rounded controls and tray popup, adds Grey/Black themes, editable workspace settings, searchable Cut-KB1–16, reviewed issue uploads and default-on backups. The Word guide includes a real screenshot of synthetic footage, 17 stable bookmarks and 67 verified internal navigation links. Its eight-page layout is rendered and reviewed before publication.

Source and packaged desktop checks run on Windows x64, macOS Intel/ARM64 and Linux x64. Each decodes two independent video items and draws captions with Node access disabled in the renderer. Packages use software media tools for the target OS/architecture. Windows/Linux packages are unsigned; macOS is ad-hoc signed and not notarized. Portable packages have no app-owned installer/uninstaller: remove the extracted app, and remove profile data separately if desired. Launcher install/update integration uses the published catalog and checksums; interactive launcher installation and uninstall are not automated by this repository.

Window close can retain the app in the tray; Quit confirms unsaved edits or active processing. Linux tray menus use the desktop's native style. Export notifications contain generic text and the app icon; clicking restores Cut and reveals the export, and dismissing uses OS controls. Appearance includes notification and close-to-tray preferences. OS notification/menu styling and notification permission are platform controlled. Interactive tray/notification gestures and OS permission prompts still require human verification on each desktop environment; automated startup checks do not establish those behaviours.

Support reports redact credential-shaped values, authorization headers, home paths and URL query values before display/submission. Users review/edit the draft; the browser route sends only reviewed text and does not append an unreviewed original crash. No real credentials, private media, or live account uploads are used in release checks. The tracked-file credential scan supplements review of the source and sanitized screenshot; it cannot prove absence of every possible secret pattern.

Local Windows smoke baseline with two paused demo sources: about 2.0 seconds to ready (including a deliberate 1.6-second smoke delay), 1.1% summed process CPU and 706 MB summed working sets. Working sets include shared pages across Electron processes and are not unique RAM. Review budget for this fixture: startup below 10 seconds, idle CPU below 30%, summed working sets below 1.5 GB; investigate increases before release. CI reports retain per-platform measurements for comparison. These are small regression fixtures, not sustained editing benchmarks. See Performance.md and FEATURES.md for remaining integration and rendering limits.

The first ARM64 packaged launch check caught an incorrect electron-builder architecture mapping in the pruning hook. The corrected hook verifies the target directory exists before removing any alternatives; a Mac ARM64 fixture now covers the failure. This packaging correction does not change user-facing KB instructions or screenshots.
