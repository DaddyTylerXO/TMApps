## Install and verify

- **Windows launcher:** run Setup. Windows Mail and the native Windows launcher require Windows 10/11 x64 with .NET Framework 4.8. Mail's HTML reader also uses Microsoft Edge WebView2.
- **Windows app ZIP:** extract the whole package and keep its supporting files together. Follow the app branch's setup guide.
- **macOS launcher:** open the matching DMG and copy the app to Applications.
- **macOS app archive:** extract it and use the included app bundle. Match Intel/Apple Silicon to your processor.
- **Linux:** allow the AppImage to execute and open it. Desktop integration, tray support and system dependencies vary; consult the app README.

Download the matching **SHA-256** sidecar and compare it with a hash computed locally. For example, in PowerShell:

```powershell
Get-FileHash -LiteralPath './TMApps-Launcher-Setup.exe' -Algorithm SHA256
Get-Content -LiteralPath './TMApps-Launcher-Setup.exe.sha256'
```

On macOS use `shasum -a 256 <downloaded-file>`; on Linux use `sha256sum <downloaded-file>`. Compare the complete hexadecimal hash. Do not run a file whose hash differs. See [SECURITY.md](SECURITY.md) for the scope and limits of checksum verification.

Windows/Linux builds are unsigned. macOS builds are ad-hoc signed and are not notarized. Packages are developing/beta software; published availability is not a claim of an independent security audit.
