# Changelog

## 0.2.0

- Redrawn purple-and-white bunch-of-keys icon throughout the app and native packages.
- Eye buttons for master, confirmation and login password fields, with automatic hiding.
- Encrypted folders: create, rename, assign/move logins, and delete folders while preserving logins.
- Settings for open at sign-in, tray/menu-bar icon, close to tray, idle locking and clipboard clearing.
- TMA-Mail-style rounded tray menu in purple, with Open, Settings, Lock vault and Exit actions.
- Closing to the tray always locks; startup always opens a locked app.
- Existing vaults remain readable; new folder data stays inside the encrypted portable file.

## 0.1.0

- Initial encrypted portable password vault, generator, expiry reminders, CSV imports, key-file protection and browser-filling extension.
