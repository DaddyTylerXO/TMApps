# Changelog

## 0.4.0

- Replace generic OAuth failures with safe setup diagnostics; preserve basic sign-in when optional metrics are forbidden.
- Add LinkedIn organization and Pinterest advanced integrations, including organization text posts and image Pins.
- Add performance reviews and clearly sourced popular-content discovery with official links for other platforms.
- Add explicit offline mode, local JPEG/PNG attachments, conditional Reddit/Pinterest fields and image alt text.
- Add visual widget setup, presets, drag ordering, shared custom check intervals and CSV exports.
- Add four navigation positions, grey/black dark palettes and gradual scheduled palette changes.
- Add an isolated first-run demo, searchable local KB articles, Word documentation and safe GitHub report forms.
- Reduce status IPC traffic, bound image storage and add automatic performance regression checks.

## 0.3.0

- Add browser OAuth for YouTube, Twitch and Kick with encrypted per-device client settings and local Google Desktop JSON import.
- Refresh expiring OAuth sessions and validate Twitch authorization hourly while running.
- Add YouTube 28-day analytics reports, keeping YouTube values separate from mixed totals and derived percentages.
- Remove account credentials, cached metrics and publishing records on disconnect; attempt remote OAuth revocation.
- Add draft Terms, Privacy and deletion documents, with a separate private HTTPS review site.
- Match release metadata to the current version when older local packages are present.

## 0.2.0

- Add multiple custom dashboards, with independent named tabs and locally saved widget layouts.
- Add statistic cards with measured up/down changes, line graphs, bar charts and pie charts.
- Configure each widget's metric, account scope, period and size; edit, reorder or remove widgets.
- Record local metric history on successful checks, with minute/hour retention and honest missing-data states.
- Keep dashboard statistics connected to manual, live and scheduled analytics refresh.

## 0.1.1

- Prefill the Bluesky handle suffix, place the cursor before it, and support pasting complete handles.

## 0.1.0

- Initial desktop beta with account analytics, supported publishing, drafts, tray preferences and automatic refresh.
