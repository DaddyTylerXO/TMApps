Privacy

Appearance & comfort

Mini window & notifications

Code updates run once per second only in visible, unlocked windows. Hidden windows stop polling. Startup adds sign-in work. Extra windows use RAM and GPU resources; password derivation uses CPU/RAM. Backups write to disk and browser links use the network. Closing unused windows reduces battery and memory use. Gradual colour transitions may add GPU work.
