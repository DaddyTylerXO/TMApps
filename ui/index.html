Settings

Desktop

Closing to the tray always locks. Startup keeps a background process running until you quit; turn it off to reduce startup work.

Security

Turning filling off closes the local bridge. Every fill requires approval. Offline only: no breach service or telemetry is contacted.

Appearance

Original Bubble layout remains the default. Choose the background palette below.

Uses this computer's local clock. Transitions update at most twice a minute while active, with a once-per-minute clock check between boundaries. Reduced motion makes changes instant.

Accessibility

Controls have semantic labels and keyboard focus for native screen readers. Optional adaptations are off until selected.

Enlargement may require scrolling. Magnification and screen readers can also be enabled in your operating system. No accessibility certification is claimed.

Password defaults

Defaults apply to future generation; saved passwords remain unchanged. Generation runs only when requested.

Help and performance

Unlocking briefly uses roughly 128 MiB for scrypt. Large imports increase CPU and disk work; locked idle operation has no vault scanning. Shorter clipboard/idle times reduce exposure, not encryption strength. Disable startup and browser filling when unneeded.

GitHub support drafts require internet and your final submission. Vault operations and this KB work offline.
